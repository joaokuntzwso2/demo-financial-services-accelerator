# Compatibility and support position

This demo uses the published Financial Services Accelerator 4.0 compatible pair:

- WSO2 API Manager 4.6.0
- WSO2 Identity Server 7.2.0
- Financial Services IAM Accelerator 4.0.0
- Financial Services APIM Mediation Policies 1.0.0 used by this demo

The repository still keeps runtime gates because product startup alone does not prove
that Financial Services endpoints, Key Manager integration, policies, APIs and TLS
trust are correctly installed.

For customer-facing or production recommendations, validate the exact WSO2 update
levels and deployment architecture in addition to the major/minor product versions.
